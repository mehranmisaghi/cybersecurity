## Introdução
A NBR ISO/IEC 27701:2019 é uma extensão da ISO/IEC 27001 voltada especificamente para proteção e privacidade de dados pessoais, abordando requisitos e diretrizes adicionais para implementação de um Sistema de Gestão de Privacidade da Informação (SGPI — PIMS em inglês).

---

## 1. O que é a ISO/IEC 27701?

A ISO/IEC 27701 especifica controles e requisitos relativos à privacidade de dados pessoais, estendendo o Sistema de Gestão de Segurança da Informação (SGSI) já previsto na ISO/IEC 27001. Foca nos papéis de controlador e processador de dados conforme a legislação internacional (como GDPR europeu e LGPD brasileira).

### Principais objetivos:
- Orientar a proteção de dados pessoais;
- Apoiar compliance com legislações de privacidade;
- Melhorar níveis de confiança entre organizações e titulares dos dados.

---

## 2. Principais Partes e Estrutura

| Estrutura                   | Descrição Específica                                               |
|-----------------------------|--------------------------------------------------------------------|
| Requisitos Adicionais       | Extensão dos controles e processos da 27001/27002 para privacidade |
| Novos Controles             | Foco em proteção de dados pessoais e direitos de titulares         |
| Papéis e Responsabilidades  | Clarifica obrigações de "Controlador" e "Processador"             |
| Transparência e Consentimento | Orienta sobre comunicação clara sobre tratamento e uso dos dados  |
| Acordos entre partes        | Define expectativas entre controladores, processadores e terceiros |

---

## 3. Exemplos Práticos de Requisitos/Controles

| Cenário                                   | Exigência da 27701                                        | Exemplo de Implementação                                      |
|-------------------------------------------|-----------------------------------------------------------|----------------------------------------------------------------|
| Consentimento para uso de dados           | Documentação do consentimento explícito do titular         | Guardar registro digital de consentimento do usuário em sistema|
| Direito de acesso do titular              | Processo para responder solicitações de acesso             | Central de atendimento realiza autenticação e fornece dados     |
| Compartilhamento com terceiros            | Análise e contrato com processadores/confidencialidade     | Contrato inclui cláusula sobre uso restrito dos dados           |
| Eliminação de dados                       | Procedimento para exclusão segura após requerimento        | Script de deleção e logs de operação de eliminação             |
| Private by design                         | Privacidade embutida em todo ciclo de desenvolvimento      | Projetar sistema prevendo anonimização e controle de acesso     |

---

## 4. Principais Diferenças: ISO/IEC 27001 x ISO/IEC 27701

| Característica           | ISO/IEC 27001                          | ISO/IEC 27701                                           |
|--------------------------|-----------------------------------------|----------------------------------------------------------|
| Foco principal           | Segurança da informação geral           | Privacidade dos dados pessoais (PIMS / SGPI)             |
| Base de requisitos       | Confidencialidade, integridade, disponibilidade | Inclui requisitos de privacidade e proteção de dados pessoais |
| Papel de controlador     | Não detalhado                           | Define controles específicos para controlador             |
| Papel de processador     | Não detalhado                           | Define controles específicos para processador             |
| Consentimento, direitos  | Não trata                                | Trata explicitamente requerendo processos e registro      |
| Conformidade LGPD/GDPR   | Ajuda parcialmente                      | Ajuda diretamente no compliance                          |
| Extensão                 | Norma de base para segurança             | Extensão da 27001 (complementar)                         |

---

## 5. Exemplo de Cenário Integrado

**Situação**: Uma clínica médica quer estar em conformidade tanto com segurança (27001) quanto com privacidade de dados de pacientes (27701).

- **Com 27001:** O acesso às informações médicas dos pacientes é controlado contra acesso não autorizado (login, senha, logs).
- **Com 27701:** Além disso, registra-se e documenta o consentimento do paciente, existe procedimento formal para pedidos de acesso, exclusão dos dados e comunicação em caso de vazamentos.

---

## 6. Um pequeno comparativo

|                     | 27001                     | 27701                                        |
|---------------------|---------------------------|----------------------------------------------|
| Abordagem           | Gestão de Segurança       | Gestão de Segurança + Proteção aos Dados Pessoais |
| Exemplos de Controle| Backup, controle de acesso| Consentimento, portabilidade, exclusão de dados|
